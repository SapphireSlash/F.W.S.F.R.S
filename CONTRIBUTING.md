# Contributing
Now, if you want to contribute, you have to follow these rules: 
* Use good grammar
* Check the preview of any pages you have changed. The preview sometimes takes several minutes before it is ready to view. Checking the preview will help you identify problems such as typos and incorrect things that should be fixed
* Make sure the text in your pull request will be easy to translate
* If there are any failing checks in your pull request, troubleshoot them until they're all passing.
